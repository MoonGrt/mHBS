# K1/K2 P1U1：128f sign 周期和综合面积

按用户确认，仅测当前 RTL 支持的 K1P1U1、K2P1U1；未扩展 K3/K4，未修改生产 RTL。使用上一轮 recipe 直接驱动 Keccak 的当前未提交工作区，新建独立源码快照和综合结果。与 `recipe_direct_keccak_20261008/direct` 的八个生产源码 SHA-256 全部一致。

共同核器件 `xc7a200tffg1156-3`；综合 `flatten_hierarchy=rebuilt`、`max_dsp=0`、统计关闭，时钟约束 6.666667 ns。**仅综合，未布局布线；150 MHz 是估算时间和 ATP 的假定值。**

# 20.9k LUT 面积优化实验

目标为共同核总 LUT（含 LUTRAM）不超过 20,900。最近已验收基线为 `value_narrow_20260930_v1`：21,158 LUT、8,582 FF、1,112 LUTRAM、6362.250 等效 Slice。保持六种 f/s 参数的 Keygen/Sign/Verify、外部接口和计算周期不变；不测新频率。

## 候选 1：SLH 固定块构造

候选标签：`slh_fixed_block_20260930_v1`，尚未验收；正式当前核指针仍为基线。

对 `N=32` 且 `RECIPE_MASK` 为 SLH 配方子集的实例，直接构造 32 字节节点的单块 SHAKE 输入：public seed、地址、左节点或链反馈摘要、可选右节点和原 SHAKE 填充。消除这一路对通用 `frame_layout` 及已选择字段的再次选择。16/24 字节路径、完整通用配方路径、Keccak、compact chain、存储和控制状态均不变。

固定块只在相应配方消费时有意义；消息和列表流式配方不读取该数据。专用路径保持原反馈优先级：反馈摘要优先于 seed/left，反馈时 32 字节路径不拼接右节点。未新增寄存器、状态或流水级。

## 验证与暂停

- 冻结 `value_narrow_20260930_v1` 的旧 recipe lane，仅重命名模块，作为独立 RTL 对照。
- 新增三组固定块等价测试，覆盖生产掩码 `101e`、`0006` 和通用掩码 `ffff`，三种节点宽度、seed/value/parent、链起始/恢复/反馈、零值/全一/随机字段和完整 1088 位块及填充比较。流式请求检查分类，不要求未消费的固定块数据相同。
- 综合前执行接口合同/lint、18 组单元、12 组正常 Keygen/Sign、6 组正常 Verify，并与冻结基线比较输出、周期及 Hash/置换次数。具体结果以候选的 `pre_synth_checks.json` 为准。
- 保存源码快照、增量补丁及完整日志，后台启动 `PROFILE_ENABLE=0` 的共同核综合后立即停止；不轮询，不自动启动下一个候选。
- 用户通知综合完成后，先检查总 LUT 不增加且等效 Slice 严格下降，再执行完整回归；通过才保留并更新当前核，否则撤回本项。后续依次尝试父节点右暂存、左暂存和 20 位地址运算；达到 LUT 目标后停止。

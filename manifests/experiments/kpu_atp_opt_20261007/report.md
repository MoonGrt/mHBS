相对旧 K4P1U1 历史参考，最终最低 ATP 高 0.075%；本轮不能据此断言流水已优于旧四核。

等效 Slice = LUT/4 + FF/8 + BRAM36×232.4 + DSP×102.4；LUT 已包含 LUTRAM。时间 = 计算周期/150000 ms；ATP = 等效 Slice×时间。Keccak 有效轮利用率 = 置换次数×24/(K×P×U×计算周期)。面积不含外部 ROM 和签名存储。

保留候选均通过四组逐字节软件参考、统计关闭一致性、停顿/复位中断/连续重放、共同核等价、异常退出以及相关 Keccak/链/多块填充单元回归；默认 K2P1U2 仍为 729983 周期，K2P4U1 仍为 486328 周期。新增节点暂存读回检查覆盖 16/24/32 字节、零步、不同链长、capture 首/中/末及 tag 复用。最终另通过 17 项原有基础单元回归和 14 项 Python 流程契约测试；旧 recipe testbench 补接新增内部读口。未扩大其他参数集/操作的性能验收。

最终控制器保留批次边界：WOTS 完成即写端点、capture 按序输出，FORS 节点按序消费。没有保留候选 3 的连续补任务和显式释放调度；不能将其较短周期作为最终版本周期。外部接口、默认 K2P1U2、微码和存储深度不变。内部增加按 tag 读取结果/capture；最终保留修正版状态复用；网表审计确认原 1600 个私有 sponge FF 已消失。置换完成时不再把末级状态写回自身，仅初始化、吸收和链反馈需要显式写入。

实验目录：`manifests/experiments/kpu_atp_opt_20261007/`。每个候选保存源码快照、配置、补丁、完整日志、仿真结果及四组分层面积报告；最终报告路径为 `<候选>/K1P<n>U1/core_hierarchical.rpt`。复现单个新候选：`python3 scripts/run_kpu_atp_candidate.py --candidate <新标签> --best <前一最低ATP>`。以对应快照源码运行，不能直接用最终源码代替历史候选。

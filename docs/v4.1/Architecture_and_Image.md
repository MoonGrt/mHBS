# μHBS v4.1：共同硬件与独立镜像

工程版本 **v4.1**，指令 ABI **4**。V3 与 V4 原始证据保持归档。

## 执行流程

`uhbs_top` 的输入只有 `clk`、高有效 `rst`。复位异步置位、两级同步释放。

复位释放 → 校验三个镜像 → 装载 Job → Keygen → 从 program 读取消息 → Sign → 停机。

`done` 或 `error` 保持到复位。每次复位最多一次签名。`out_valid` 指示当拍结果，
`out_keep` 指示 `out_data[63:0]` 的有效字节，最低字节先输出；无反压。
`result_kind=0/1` 分别表示 Keygen/Sign；`out_last` 表示对应输出的最后一拍。
`boot_cycles` 单列镜像校验与装载成本，`keygen_cycles`、`sign_cycles` 包括操作中的 ROM 访问。
Hash/置换计数在每个操作开始时清零；在 `keygen_done` 和 `done` 处分别采样。

## 三个独立 ROM

| ROM | 容量 | 逻辑读取延迟 | 内容 |
|---|---:|---:|---|
| program | 64 × 128 bit | 组合读取，消费者在时钟沿采样 | 指令、Job、消息 |
| template | 64 × 128 bit | 同上 | 操作模板 |
| descriptor | 128 × 64 bit | 同上 | 参数、配方、树操作、路由 |

多个 descriptor 读取端口通过物理存储复制实现；复制存储计入总面积。
`.mem` 每行一个十六进制逻辑字。Job/消息字节按低位到高位排列。
算法定义的大端整数编码由配方单独处理。

| program 地址 | 内容 |
|---|---|
| 0–31 | ABI 4 指令；有效区后的字必须为零 |
| 32–33 | secret seed，32 字节槽 |
| 34–35 | secret PRF，32 字节槽 |
| 36–37 | public seed，32 字节槽 |
| 38–39 | randomizer，32 字节槽 |
| 40 | identifier，16 字节 |
| 41 | 控制字段，见下表 |
| 42–43 | 保留为零 |
| 44–49 | 1–87 字节消息，尾部填零 |
| 50–63 | 保留为零 |

| 控制字 41 位段 | 含义 |
|---|---|
| 10:0 | 初始索引 q |
| 17:11 | 消息字节数 |
| 23:18 | 有效 program 指令数，1–32 |
| 30:24 | 有效 template 数，1–64 |
| 127:31 | 保留为零 |

短于 32 字节的节点槽高位填零。SINGLE/RUN/LOOP/HALT 原编码不变；
入口保留在 descriptor 0，profile 在 descriptor 1。指令禁止进入 Job/消息区。

## 为什么替换镜像不会改变面积

处理器先以通用 ROM 数据端口独立综合，不提供任何算法或初始化常量。
ROM 与复位适配器独立综合，再链接处理器检查点。ROM 使用固定容量分布式存储原语，
初始化内容在实现后修改；不会通过重新综合把内容传播到处理器。
七个镜像共用节点宽度 32 字节、摘要宽度 49 字节、133 条链的硬件容量。
`LANES`、`UNROLL` 是共同硬件候选参数，七个镜像必须使用同一个取值。

验收需证明七份检查点除 ROM INIT 外，单元、连接、位置、布线均一致，
并使用一个共同面积和一个共同频率计算七组 ATP。仅源码相同不能证明面积相同。

## 索引语义

XMSS/LMS 的认证路径缓存只保留选定 q 的路径。内部先记录 q+1，再确认签名请求，
确认前不能输出签名字节。同次运行失败不回退已经消耗的索引。
这是固定向量基准接口：复位清除易失状态并允许重放，没有非易失持久化保证。

## 软件先行证据

`manifests/experiments/unified_hbs_v4.1/software_gate.json` 封存模型与测试源码哈希。
软件门禁通过后才修改 RTL。解释器仅从三个镜像解码 Job、消息和算法配置，
检查完整输出、Hash 输入输出序列、计数、缓存和索引状态；原独立模型/KAT 测试同时运行。

## 比较边界

与论文的比较为 **NON_STRICT**：SLH-DSA 与论文 SPHINCS+ 的版本不同；
LMS 使用 SHAKE256/256 研究 profile；消息和密钥是固定向量；状态算法采用选定路径缓存。
v4.1 的共同最大容量硬件与 V3/V4 的分别静态综合面积含义不同。
实际资源与周期、时序及 ATP 是否通过，必须以验收报告的已完成证据为准。

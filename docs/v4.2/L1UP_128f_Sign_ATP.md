等效 Slice = LUT/4 + FF/8 + BRAM36×232.4 + DSP×102.4。时间 = 计算周期/150000 ms；ATP = 等效 Slice×时间。Keccak 利用率 = 置换次数×24 / (L×U×P×计算周期)，表示有效轮运算占物理轮容量的比例。

四组签名逐字节通过软件参考比较，Hash/置换次数均为 104937/105641；统计关闭输出和周期一致。四组输入停顿、复位中断与连续重放，P3 单 lane 交换，P4 共同核等价和两项异常退出均通过。现有存储、父节点操作数及输出来源监视器同时运行。L2U1P1/P4 的输出、周期与此前冻结测量一致。单 lane 新配置本轮只验证 128f sign，其他参数集与操作尚未验证。

源码快照、配置、日志、CSV/JSON 及分层面积报告：`manifests/experiments/l1up_128f_20261007_v1/`。各点 `core_hierarchical.rpt` 为分层报告；综合关闭统计并检查计数寄存器裁剪。没有测量新频率。

本组最低 ATP 为 L1U1P4：42458.153 Slice·ms，较 L1U1P1 降低 41.33%；较此前同口径 L2 最佳点 L2U1P3（48147.044）降低 11.82%。L2 面积引用冻结实验，本轮只对 L2 做周期回归，没有重新综合。

# SHA2 长度元数据共享优化

候选：discarded。本轮比较基线为上一轮保留的固定窗口版本 `20261019_175821`，不把最早版本的大幅面积下降重复计为本轮收益。

Hash输入长度在请求接收时计算并登记，后续KEY/MASK/FINAL/HMAC/MGF与链阶段切换时更新固定长度，删除每槽arity数组。格式化和Hash完成判定直接读取长度寄存值，缩短选槽后的译码路径。输出长度改为一个标量寄存器；批量结果长度固定不超过32字节，不读取标量长度决定是否继续MGF。减少逐槽输出长度银行及返回端的标签选择。SHA256原语、轮询仲裁、列表预取、格式化窗口和所有执行拍数均不变；没有P/U特化。

共同核common、xc7a200tffg1156-3、Vivado 2025.2、100MHz、OOC、默认时序驱动，每进程2线程。等效Slice = LUT/4 + FF/8 + 232.4×BRAM36 + 102.4×DSP。未布线；综合时延不能作为实测最高频率。

验证：P4U1普通与P12U1综合视图各345项配方，共690项，以及12组批配方通过。九项整核Sign全部通过，周期、Hash/压缩计数和向量与上一版本完全一致，完整输出和签名缓存逐字节核对；另有9项异常/停顿/复位回归、4项NIST ACVP完整签名及3项综合视图Sign。另有独立hashlib计算的专项测试：34/30/34字节标量摘要与批量MGF交替、无复位重放和返回停顿，证明批量请求不受标量输出长度影响。SHA256原语未改变，不重复原语验证。

面积、时间和ATP均以未舍入数据比较。100MHz为统一假设频率，面积×周期×综合路径仅作诊断。原有双后端长回归不因本轮修改而停止；本轮不运行h20完整树。

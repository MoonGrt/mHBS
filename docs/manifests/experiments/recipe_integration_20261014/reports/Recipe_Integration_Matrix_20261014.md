## 最终选择

最终采用 **shared_control（`20261014_143751`）**：删除独立 pipeline 模块，消除重复响应标志并共享 P1 轮计数；状态 word 保留原写入选择。工作区已恢复到该候选的精确生产源码，不能将 word_write 的验证或面积当成最终实现。

选择时 shared_control 已完成 13 个面积点：10 点下降、3 点增加，剩余 P6U2 继续后台。已完成 13 点的等效面积算术平均下降约 0.638%；这只是各配置等权统计，不代表 14 个核同时实例化的面积，也不是全 14 点结论。P4U1、P12U1、P1U2 分别回退 1.300%、3.528%、2.695%，因此本轮没有实现所有配置面积下降。前面的主表会随后台结果更新，选择时的统计保留在此。

三种算法在同一 P/U 下周期均保持相同，所以该点 ATP 百分比变化等于面积变化。现有结果中 SLH 128f 的最佳 P12U1 ATP 也回退 3.528%，不能宣称三种算法最佳 ATP 同时改善；本轮兑现的是模块合并、周期不变及多数配置面积降低，并明确保留上述局限。

word_write 初始完成的 P1/P2/P3/P4/P6 U1 五点面积全部回退，P4U1 增加约 12.451%，故整项撤回。它的其余综合继续后台补齐对照，不自动替换已选择的 RTL。机械合并与宽数据选择重写均说明，源码变短或消除重复表达式并不保证综合面积下降。

## 结构调整

基线为提交 `61034b8` 对应的本轮冻结源码 `20261014_143018`，完整重测原 14 个 P/U：U1 的 P1/2/3/4/6/8/12/24，U2 的 P1/2/3/4/6/12。基线已包含上一轮配方及 L-tree 优化，没有借用更早实验配方的周期或面积。

删除 `rtl/hash/pipeline.sv` 及综合、仿真清单中的依赖。固定块格式化、配方/链状态、上下文银行、响应仲裁全部直接位于 `recipe.fixed_context`，不再以另一个模块或 include 文件替代原模块。真正保存 Keccak 每级状态的是 `recipe.stages`；一个 `recipe` 同时拥有配方执行与置换数据通路。

P 个上下文仍然只共享一套格式化器和一条 Hash lane。P1 的上下文数组自然成为单元素，标签仲裁退化为唯一槽；没有另写 P1 算法路径。P>1 保留反馈优先、滚动补发、乱序完成、有序捕获与响应停顿。外部 recipe/common/top 数据接口、ROM、算法参数和签名输出格式保持原样。

首候选机械核对保留原模块所有内部语句，仅更换端口绑定及 generate 包裹。N=16/24 的种子和节点显式扩展到原有 256 位内部宽度，避免内联后窄位宽改变拼接或选择行为。机械检查属于源码结构对照，不替代完整功能回归。

## 三个冻结候选

| 候选 | 源码 | 修改 |
|---|---|---|
| merged | `20261014_143419` | 机械内联，保持全部原寄存器与逐拍握手 |
| shared_control | `20261014_143751` | 合并标量响应标志与状态译码；固定/流式置换共享 P1 轮计数 |
| word_write | `20261014_144909` | 在 shared_control 上合并状态 word 的写入选择 |

`bridge_response` 在所有正常可达状态中等于 `state == FIXED_WAIT`，可直接由 FSM 译码。固定与流式置换串行使用 P1 唯一的 Keccak 状态，所以可共用一个五位轮计数器：固定请求接受或流式最后吸收拍清零，未完成的轮运算递增；固定末轮同拍反馈重发优先。多级流水仍使用原各级的轮编号，P1 控制不参与其执行。

word_write 将原嵌套条件展开成每个 64 位 word 的单写使能。非零写数据只可能来自固定输入、吸收数据或轮运算结果，清零拍保持写使能但写入零。固定加载优先级、共享末级吸收优先级和 `SHARED_STATE=0` 的私有 sponge 路径均保留。独立脚本穷举 2,048 组控制组合，覆盖相互冲突的输入控制，也与原选择规则一致；不依赖把这些组合假定为不会发生。

是否采用进一步清理由完整 common 综合决定。删除模块边界本身不保证 LUT 减少：Vivado 会重新进行控制、选择器及状态机映射；不同 P/U 的面积可能反向变化。对照使用每个候选自身的面积及周期，不能逐配置挑选不同 RTL 拼成一份最终结果。

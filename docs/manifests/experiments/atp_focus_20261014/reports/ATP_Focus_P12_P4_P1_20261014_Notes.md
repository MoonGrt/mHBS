## 最终实现与取舍

最终采用 `20261014_113650`，三个配置使用同一份RTL。相对于修改前提交 `ace6310`，改变 `executor.sv`、`pipeline.sv`、`recipe.sv`；保留原模块端口和例化的紧凑布局，未加入 P/U 特化或新增 Hash lane。

- 固定请求在外层 ready/valid 握手当拍进入上下文引擎，完成结果保持在原上下文中直到上游接收，删除发射和返回各一个空拍。
- XMSS L-tree 最后一个响应写回时直接推进下一批或下一层，删除单独的 ADVANCE 空拍及每棵 L-tree 的首个 SETUP 空拍。仍等整批输入接受后才写回，奇数尾节点保持原处理规则。
- FORS 同一波内相邻二元请求连续发射；RAM 读地址已在上一拍登记，无需在两个请求之间再等一个 LEFT 状态。仍使用通用四叶微组。
- 父节点左输入与结果复用 `result`，删除256位 `task_left0` 及其选择路径。LMS叶节点原本就是复制 `result`；左输入在哈希结果到来时已结束使用。右节点、树栈、认证路径和签名缓存的同时存活关系不变。
- 上下文阶段采用独热位，保留 key/digest/captured 三个同时存活银行并显式指定分布式RAM映射。没有据此宣称所有 P/U 的局部阶段均能降面积，取舍依据整个 common 的实际综合。
- 流式填充共用剩余长度计算；节点读取使用上游已限定的两位字索引；小型 source/index/literal 选择控制提前一拍登记。START 提供首拍控制，之后当前拍同时计算下一拍，停顿时保持控制，不增加节点级数据缓存或周期。16/24/32字节节点、LMS 22字节前缀和136字节率块的最后8字节均保留。

三点九项的Hash/置换计数和全部输出均一致。P12U1、P1U1的面积下降，P4U1面积增加7等效Slice（约0.073%）；P4U1的LMS ATP增加约0.017%，其余八项ATP下降。三个算法在本轮三个配置中的最佳ATP均下降；不把这一结论扩展到未重新测量的其余P/U。

显式展开固定格式帧、对整个Keccak状态做互斥位掩码、并行重写 next_phase 等候选没有纳入最终实现。它们在部分点减少LUT，在另一些点增加选择或门控开销。表中的逐阶段面积是各自冻结源码的真实结果，不把不同候选的最佳数值拼接。尚未完成的旧候选只跳过分析，继续后台综合。

## 周期收益归因

| 改动 | P12U1节省周期 | P4U1节省周期 | P1U1节省周期 |
|---|---:|---:|---:|
| SLH固定请求桥接 | 1,292 | 1,292 | 1,292 |
| SLH FORS连续发射 | 1,188 | 528 | 0 |
| XMSS固定请求桥接 | 2,048 | 2,048 | 2,048 |
| XMSS L-tree首拍与批间空拍 | 11,264 | 21,504 | 68,608 |
| LMS固定请求桥接 | 4,094 | 4,094 | 4,094 |

以上按状态改动与实测周期差分解：XMSS每个叶子的L-tree批次数在P12/P4/P1分别为10/20/66，加每棵树的首个SETUP拍，总计1024×(批次数+1)。其余面积优化不改变周期。P1已接近单轮Keccak吞吐下界，继续大幅降低周期需要改变置换吞吐或处理哈希间依赖，不能只靠压缩控制状态。

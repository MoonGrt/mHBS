# H3：P12U2 单点旁支诊断

本实验仅进行 **SHA2 P12U2 common、100MHz 综合诊断，以及自身三个完整 Sign 和同源 36 组功能检查**。未请求布线，不能作为 100MHz 实布通过或 14 点频率验收证据。

冻结 SOURCE：`a7f2267cd420f3c06bfed92233ae26ddfd1c829dcb4f971fd211908dbe5ec04a`。继承 I 冻结输入 `4350a4db61a8b68e2428733ad05e85eb17a6818d41f9e8a6998a235834f34da9` 的 644 项，只替换 SHA256 core 为 H3 `ef6c9c04105b3eab91b24634ca2fd115611bd7d2eae95c44e7e439890622c13f`。生产 I 和旧任务保持运行。

H3 仅将 next_a/next_e 最后加法改为 16+16 carry-select，调度和消息展开不变。原语全部 30 个合法 P/U 的正常/综合双视图均通过，周期、停顿、标签和复位结果与 H2 一致。新增高半段加法副本和选择器，尚未证明面积、时序或 ATP 收益。

动态面积、关键路径和三个 Sign 的自身实测结果见同目录 `SHA2_Timing_F_20261022_121638.md` / `.json`；当前未测结果留空。该报告的 E2 基线为独立历史对照，不是 H3 测量值。本实验不借用 I 的面积或周期。

全局 12 个 Vivado、每个 2 线程的原容量锁保持启用。冻结 RTL、support、源码与控制器校验、helper、来源补丁、综合分层/时序/Vivado 日志归档；sim/validation 明细留在运行目录。无 README 或 CSV。

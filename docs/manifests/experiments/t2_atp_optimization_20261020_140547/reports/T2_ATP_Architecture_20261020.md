# T2 基础面积、延迟与 ATP 优化取舍

本轮工作区保留冻结 **U5**（20261020_140547），基线严格为冻结 T2（20261020_115729）。U5 的 P12U1、P4U1 common 综合面积及100 MHz诊断路径均优于T2；三种 Sign 的固定100 MHz假设ATP均降低。本轮没有布局布线，物理频率与布线ATP尚未验证，已有T2的149.9925 MHz闭合结果仍为物理参考。

## 测量范围

同器件 xc7a200tffg1156-3、Vivado 2025.2、common OOC、通用 Keccak、SYNTHESIS统计裁剪、默认时序驱动综合、10 ns约束，每个Vivado两线程。不新增时序例外、不改变Hash lane数量、端点容量、ROM格式或外部接口。所有优化沿既有P1标量／P>1调度结构实现，没有新增P/U特化。h20完整Keygen、Sign未执行。

## 改动及生命周期依据

1. **U1 返回控制预取。** 原T2实际P12U1布线最差路径由末级tag经phase/iteration等选择进入launch_state，6.623 ns、8级LUT，布线占81.8%。在既有倒数第二级操作数预取边界，同时准备下一phase、块格式、链步和捕获判断；完成周期使用这些寄存值。删除逐槽feedback_format银行，格式只在预取位置计算。每tag仅一个置换在途，busy阻止复用，上述字段在dispatch至返回期间稳定；debug逐字段核对。没有额外功能周期。
2. **U2 共享写回选择。** 端点RAM始终一个写口；先登记direct writeback阶段所有权，再将互斥写入源平坦合并。SLH、XMSS、LMS按Job互斥，阶段写入者互斥；认证与树栈同存活时仍先认证、下一PUSH_STACK拍写树栈。保留原优先级逻辑作为仿真oracle，并断言onehot0，未减少存储容量或覆盖在用节点。
3. **U3 删除重复容量暂存。** 固定单块的Keccak容量512位恒0；流式置换在launch待消费期间不吸收新数据、不完成另一置换，因此既有sponge容量区保持稳定。launch只暂存1088位rate，首级容量复用sponge，节省512个宽暂存FF及相关选择逻辑。不新增数据流水级。独立原1600位launch容量快照oracle逐拍比较，覆盖非零容量与待消费复位重放。
4. **U4 响应队首预计算。** 队列bitmap与其下一优先tag同拍登记，宽key/digest/capture银行读由已登记tag驱动。保留原发布拍，完成数据先提交银行；next-mask仍按publish清除、zero请求置位、完成置位的原优先级更新。原组合优先tag oracle保留，发布顺序、停顿及同拍复用不变。
5. **U5 滚动回收反馈切断。** 空闲槽只从已登记pipe_active选择，去掉响应valid同拍退休到roll_free、优先编码、请求tag、ready的组合回路。返回槽下一拍可分配，其他已空闲槽照常使用。功能工作量不变，完整Sign额外周期为0.061%～0.214%。P12U1诊断路径由U4的response_held→intake/R 6.123 ns变为pipe_active→intake/R 5.259 ns；P4U1剩余主路径为树节点索引到node_level控制。

三银行key/digest/captured及独立签名缓存继续保留，因为同一XMSS操作内存在重叠存活期。本轮没有把LUT面积转移到BRAM，也没有新增Hash lane。

## 候选取舍

五个冻结候选均保留，包括回退项。U1和U2在P12的综合路径回退，U3的P12面积仍略高于T2，因此未单独采用。U4两点面积下降且零周期增加，是P12固定100 MHz ATP的最佳对照，但P12诊断路径6.123 ns比T2的5.575 ns长。

U5比U4的P12面积仅少6.5 Slice，增加少量周期，所以P12固定频率ATP比U4略高；选择U5是为了让两配置面积、对T2的固定频率ATP和诊断路径同时改善。保留U4用于后续物理比较。**U5是待布线候选，没有新的实际频率或布线ATP结论。**

## 验证与证据

- 五候选各P12/P4三个目标完整Sign，共30项；输出、签名缓存逐字节核对，Hash/置换及向量SHA与T2一致。U1～U4周期完全相同，U5周期如表。
- 五候选各76项补充验证，共380项通过：包括配方KAT、正常/SYNTHESIS视图、乱序返回、同拍退休补发、捕获停顿、公共地址切换、P2/P6兼容、P1标量、奇数L-tree、FORS微组、消息与填充边界、篡改、截断、复位、在途故障，以及仅用已有向量的h20 Verify。
- U2共享工作区专项P1/P4/P12共3项通过，独立逻辑/物理存储scoreboard核对认证优先、栈延后、奇数L-tree及地址保护；DEPTH136子模块检查135/134尾槽，executor自身工作区上限127。
- U3容量复用recipe子模块5组、2295条独立hashlib配方通过，测试recipe与U3冻结recipe字节一致。U3/U4归档的1,385,320个priority次态组合是独立逻辑模型证明，不替代RTL回归。
- U5独立滚动回收probe六Sign结果与主运行一致；其executor与U5仅两行注释不同，真实SHA和精确差异均记录，没有借用结果冒充冻结RTL实测。

# 八轮面积优化：P1/P4/P12U1

先对七种独立结构修改测量，再组合实测有效项作为第八轮。每个候选均从同一冻结基线生成；不将各版本最低面积拼成统一核的结果。最终采用同一份 RTL 的测量，失败与回退候选保留。

三个目标为 SLH-DSA 128f、XMSS h10、LMS h10 Sign。每轮执行九项完整 Sign，逐字节检查输出、签名缓存，并与当前冻结基线比较周期、启动总周期及 Hash/置换计数。本轮将“周期基本不变”按完全一致验证。

面积为同器件 xc7a200tffg1156-3、通用 Keccak、SYNTHESIS、OOC、6.666667 ns、默认时序驱动综合的 common；不含外部 ROM/签名缓存。最多十二个 Vivado，每个两线程。所有新运行预留旧矩阵剩余并发容量。超过十分钟只暂缓分析，综合继续运行；未完成数据留空。

等效 Slice=LUT/4+FF/8+232.4×BRAM36+102.4×DSP；时间=周期/150000 ms，ATP=对应配置等效 Slice×时间。150 MHz 为假定频率；未做布线 STA。

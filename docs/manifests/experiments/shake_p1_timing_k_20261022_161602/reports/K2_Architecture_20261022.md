# K2：分组端点译码，保留J1共享执行器

此冻结候选只有SHAKE recipe标量分支与J1不同，executor、SHA256及SHA2 recipe均逐字节恢复/保持J1。避免将尚未证明的共享控制改动带入已闭合的SHA2实现；全部配置仍重新测试，证据不混合。

K1的68位按字节译码控制使面积增加，100MHz诊断关键路径转到task_step→endpoint_controls。K2改为14位分组控制：对齐字4位、偏移字低48位4位、高16位4位、相邻节点与LMS前缀各1位。现有有效字节掩码在数据末尾共享门控，去除控制译码中的输入长度/填充判断，减少54个声明控制位。实际综合裁剪数量及收益以报告为准。

不新增节点数据寄存器，不改ready/valid、预取地址或流生产周期。正常和综合视图的P1U1配方检查各459例通过，均为12627停顿周期，与K1一致，覆盖节点长度和135/136/137填充边界。旧节点拼接表达式及独立等价oracle全部由ifndef SYNTHESIS包围。

两后端的P1U1/P4U1/P12U1/P4U2，执行8点100MHz common诊断、24项完整Sign、36组功能验证；单点门禁通过后分别在6.666ns或10.000ns布局布线。100MHz仅作诊断；最终必须通过实际setup/hold、完整路由、零DRC及实际目标频率。h20完整树停止。

K1继续后台并保留失败/面积回退证据；本候选不覆盖其冻结源码。面积、周期和ATP结论等待实测，报告60秒刷新、完成退出。

从 `80e5d3ff` 干净基线重新试验。保留 K1U1、单 Hash lane、program16/template16/descriptor32、SHAKE/SHA2 和原标准镜像；本轮不布线。

采用 T5：SHAKE 将原先“9选1读取128位旧状态再扇回”的吸收网络改为每字本地异或；CHAIN_STORE 在无需捕获输出且未到最后一条链时，同拍写端点、推进链号并直接进入 CHAIN_SETUP；SHA2 单上下文下直接使用压缩器现有保持输出作为后续块CV，首块选择IV，删除recipe的冗余CV副本；多上下文仍保留各tag CV。原scalar_result、digest、key、captured银行及全部合法配方语义恢复保留。未新增节点银行或 Hash lane。

T2 的消息共享虽减少宽寄存器，却引入更大的共享写入及读取选择；父节点直接响应又增加 lane_value→node_value 宽选择，合成后总面积上升。因此没有用功能通过替代ATP验收。T2冻结源码、综合和独立生命周期拒绝测试均保留在失败候选归档；最终已经撤回消息共享、模型生命周期检查和300b故障条件，四个逻辑value的原独立存活语义恢复。

源码证据：[冻结RTL](../candidate_rtl.tar.gz)、[生产文件校验](../RTL_SOURCE.json)、[SHAKE分层](../synthesis/shake/hierarchical.rpt)、[SHA2分层](../synthesis/sha2/hierarchical.rpt)。原始附加测试日志保留build，归档仅保留摘要和源身份；完整各阶段综合日志及RTL也在对应`synth_*`实验中。

T3/T4的digest与scalar_result别名也已全部撤回。T3只满足标准镜像，普通SLH自编output_bytes>16及标量期间raw读口存在差异；T4保全旧视图后又面积回退。因此最终T5保留原两套结果语义，改为复用原语早已保持的CV。SHA256 output_cv仅完成压缩时更新；单上下文没有其他tag覆盖它，下一块按block_index选择IV或该保持值。多上下文仍需要独立CV银行，属于上下文存活期带来的自然结构差异。

高树只运行真实高度Verify；h16/h15/h20完整Keygen/Sign未启动，h20完整树保持停止。未测布线频率、未使用时序例外、未产生报告CSV。

# U5 后续面积、延迟与 ATP 优化取舍

本轮保留 **V8**（20261020_152253）。唯一比较基线是冻结U5（20261020_140547）。V8使P12U1/P4U1 common综合面积及固定100 MHz假设ATP分别降低1.306565%/0.187940%，六项完整Sign周期全部不变。P12U1综合诊断路径略降，P4U1路径回退；本轮没有布局布线，实际频率与布线ATP仍未知。

## 实现与生命周期依据

- **请求寄存器由valid位管理。** `pending_valid`保持原接收/派发握手；宽payload在队列空闲或旧项派发时采样，阻塞的有效请求保持。无效payload不进入上下文或Hash。原receive快照在仿真中逐字段核对；这一改动切开选槽/ready与宽寄存器使能的关系，不改变周期。
- **提前准备滚动选槽。** 与`pipe_active`更新同边沿计算并登记下一最低空闲tag及available。遵守U5的退休后下一拍可补发规则，保持同拍完成/提交的原优先级；不增加等待。原bitmap、顺序不变量和独立所有权模型核对。
- **提前准备树父路径判断。** 1位`target_parent_match`随node_index/target_at_level一起更新，用于原PARENT_SETUP分支。宽比较移到坐标更新边沿，阶段/地址语义不变；保留比较原表达式的不变量。P1标量仍保留，其父路径行为一致。
- **V8格式化数据选择由valid保护。** V2的P12最差路径是core_released→core_rst→again（扇出1011）→块格式化→launch_state，5.689 ns、11级。功能`again`、ready/valid、统计和存储提交仍带原复位屏蔽；仅9处宽块数据选择使用未屏蔽复位的stage-valid/fixed/feedback条件。复位有效时`launch_ready=0`，这些数据不会被launch寄存器采样；复位无效时新选择与again逐拍相等，并有仿真断言。没有移除功能复位，没有添加false-path或multicycle。

所有变更沿既有通用P/U结构实现，没有新增某个P/U独占路径，没有额外Hash lane、BRAM或节点缓存。算法、ROM、外部数据接口及完整认证路径重算保持不变；模块端口和例化紧凑布局未展开。key/digest/captured银行继续保留，因为其存活期存在重叠。

## 八候选取舍

| 候选 | 独立变更/组合 | 结果与取舍 |
|---|---|---|
| V1 | 放宽无效intake数据采样使能 | P12小降，P4面积及诊断回退，单独不保留 |
| V2 | V1加选槽/父路径预计算 | 两点固定频率ATP改善；保留为P4最佳对照 |
| V3 | V2合并SLH32/XMSS公共块布局 | P4面积回退，未采用 |
| V4 | V3合并两份128位流式暂存 | FF减少，但RAM后多一层选择且LUT/路径代价抵消，未采用 |
| V5 | U5加独立选槽/父路径预计算 | P12面积/诊断均改善，但P4面积回退，保留单点对照 |
| V6 | V5在LOAD_DESCRIPTOR提前登记FORS组基址 | P12路径较短，面积代价更高，未采用 |
| V7 | U5流式置换直接进入首级Keccak | 周期下降但面积上升，整体收益未达标，未采用 |
| V8 | V2加valid保护的无复位数据选择 | 本轮P12三算法假设ATP最低，两点面积均降，保留 |

V7的六Sign周期实测节省：SLH两配置各882、LMS各16385、XMSS各1；Hash/置换次数及输出不变。但其common面积分别增加0.384606%/1.434351%，使六目标配置中只有P12 LMS的假设ATP下降。因此没有因为周期下降就采用，也没有把结构推导或历史stall计数当成实际总周期。

V8的P4固定频率ATP不及V2（V2为9486.500 Slice），而且其诊断路径比U5长11.0684%；这一回退保留，不把不同源码的P12/P4面积拼成一个候选。选择V8是因为P12在本轮两配置三目标中有更低的同频ATP，V8又使其三项达到本轮最低，同时P4面积仍略有下降。实际闭合频率及布线ATP需要另行验证；本轮没有启动布线。

- V7独立hashlib配方2754例（六组），包含shared/private、P2U12单遍历及SYNTHESIS；P1 scalar代码与U5字节相同。完整周期收益来自主运行器实测，不从缺少cycles/source绑定的旧日志外推。

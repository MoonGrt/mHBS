# SHA2 J recipe: overlap descriptor reads and pipeline list fetches

The recipe component is frozen at `c19f147142ac6632f288b2cdc93f0c467824fba0f70f8e0356606a41f0c8fd92`, based on I `924a8a28b23a1515c7b2fc522af354abc958980acbb78bfd4aaae7e531d07e61`. It is included in combined candidate manifest `e59fee9453346d684880b1e0e2ac2ec45a815d0ef764263f36642905ec85a7c7`.

A small `block_ready` flag and held compression tag replace the formatter's SEND state. Once a prefix block is written or the final staged ordinary beat commits, the next context can be reserved. Its descriptor read overlaps the preceding compression-input handshake. If SHA256 recycles and refuses input, DESCRIBE waits; the old CV, tag and all 512 block bits remain stable. The tag-selection, descriptor, endpoint-word, source-window and byte-alignment register boundaries are retained. There is no second block buffer, context bank, hash lane or P/U special case.

The three next-beat word selectors (27 bits) are registered with the current selectors. While retained list words enter `source_window`, the same three list-word registers fetch the following beat. The endpoint address looks ahead by two beats when a source beat is consumed and by one when priming the fetch stage. The combinational `list_index0/1` outputs describe the beat being fetched; `list_next_index0` describes the address the executor must register for the next cycle. Tests use both the original combinational adapter and a separate adapter that registers the next address exactly as the executor does. Existing 512-bit block storage and 192-bit list/source stages retain their capacities.

The initial private prefetch version did not advance the combinational list-index outputs. Independent recipe tests detected that mismatch; the final version corrects it and passes both endpoint adapters. That precursor was not accepted and did not launch hardware measurement.

Final component validation passed 1,035 scalar/hashlib cases (P4U2 SYNTHESIS with combinational endpoints, P12U1 normal and P1U1 SYNTHESIS with registered endpoint addresses), 12 four-live-tag groups (96 requests) and three all-24-context groups (144 requests). The exact SHA256 primitive in these tests is the combined J CV-history variant `e7affefe71404930b739dd8d8ccab23a118628be75e8455a9cc4e932dd185e4f`. Raw logs remain in the run directories; this evidence bundle contains summaries, sources and tool identities.

Separate cycle attribution freezes the same I SHA256 primitive for I, the first overlap-only recipe, and the final recipe. Across 345 scalar cases at P12U1, overlap alone changes no single-context latency; the list pipeline improves 33 cases and regresses none. The 67-node SLH list falls from 1,625 to 1,571 cycles, and the 67-node LMS list from 2,924 to 2,822 cycles. These are recipe-level measurements, not complete Sign predictions. At full 12-slot occupancy, overlap alone changes SLH/XMSS/LMS stress-bench cycles from 5,213/14,946/2,736 to 5,195/14,910/2,727, retaining all expected hashes, compressions and captures.

Area, final setup/hold, routing, DRC and ATP must use the combined candidate's own common synthesis and physical results. No frequency or ATP improvement is claimed from component tests.

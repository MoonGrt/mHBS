## 2. 测量配置与口径

- 编译器：`/media/sk1/25700d07-be6e-4225-bd06-13baa4403116/Vivado/ascon-sign/tools/cva6/toolchain/bin/riscv-none-elf-gcc`；GCC 13.1.0；`-O2 -march=rv32imc -mabi=ilp32 -DNDEBUG`。
- 平台：SLotH 自带 `pug_rv32` CPU、默认硬件哈希核、Verilator RTL 仿真；不是 VexRiscv/Ascon 平台。
- 正确性：各参数 KAT 私钥及签名+消息校验码、正常验签和翻转位拒绝均通过；没有声明重新逐字节比较完整 `.rsp` 文件。
- 边界：从 `slh_keygen`、`slh_sign`、`slh_verify` 入口指令执行周期开始，到返回地址处指令执行前结束；排除测试框架、校验码计算和第二次翻转位验签。
- 独立固件与仿真进程的主机并发影响运行耗时，不改变单个操作的仿真周期。

| 分类 | 含义 |
|---|---|
| 哈希运行 | 硬件实际推进周期；与 CPU 轮询或 MMIO 重叠时优先归此类 |
| 通讯 | 其余周期中哈希 MMIO 总线占用周期，不是整条 MMIO 指令的执行耗时 |
| 输入构建及其他 CPU/内存 | 总周期扣除前两类；包括输入处理、地址、树遍历、内存、随机数和控制，不能当成纯输入拼接 |

三类互斥且相加等于总周期。CPU 等待不能重复相加，硬件运行也不能全部视为可隐藏的独立计算量。
SHAKE 统计 Keccak 轮及内部链推进；SHA2 统计装载、填充、PRF 设置、轮计算和最终相加。
SHA-256 数据窗口访问会暂停状态机，暂停周期不计运行；状态寄存器轮询允许继续执行。仅预装 CHNS、尚未触发不计 SHA-256 运行。
SHA-512 状态机独立于 MMIO 分支推进。SHA2-128s/128f 仅使用 SHA-256；192/256 参数同时涉及 SHA-256 和 SHA-512。

## 8. 主要发现与结论边界

- keygen：同参数 SHA2 / SHAKE 周期比范围为 1.742×（256f）至 2.016×（128s）。
- sign：同参数 SHA2 / SHAKE 周期比范围为 1.853×（128s）至 2.387×（192s）。
- verify：同参数 SHA2 / SHAKE 周期比范围为 1.474×（128s）至 2.193×（192s）。
- SHA2 签名最大类别：128s：哈希运行 77.96%；128f：哈希运行 77.86%；192s：输入构建及其他CPU/内存 51.27%；192f：哈希运行 48.77%；256s：输入构建及其他CPU/内存 58.53%；256f：哈希运行 47.36%。
- SHAKE 签名最大类别：128s：哈希运行 53.47%；128f：哈希运行 53.43%；192s：输入构建及其他CPU/内存 55.18%；192f：输入构建及其他CPU/内存 51.94%；256s：输入构建及其他CPU/内存 61.77%；256f：输入构建及其他CPU/内存 54.39%。
- 每行只测首个 KAT，不代表跨消息、随机密钥或签名的平均值、方差与最坏情况。不同参数或不同算法之间不能只按轮数、总周期推断安全性或硬件效率。
- CPU/内存剩余类需进一步细分后才能定位可优化工作；本表不提供纯输入拼接耗时或独立 CPU 等待周期。
- 本次整合只读取已有实验产物，不重新综合、上板或采集功耗，不修改 CPU 或加速器功能逻辑。

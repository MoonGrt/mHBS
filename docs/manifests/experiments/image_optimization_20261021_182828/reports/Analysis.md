# image F4 面积与软件控制周期优化

完成：True；通过：True。基线为 image 软件CHAIN实验 `soft_chain_20261021_173641`，代码基点 `394a6993`。

链、链号、链步、捕获、L-tree和Merkle/FORS树遍历仍由layout5程序控制；20组ROM逐字不变。不增加Hash通道、不引入CHAIN/TREE宏或参数专用实现。

## 改动与边界

- 纯算术、分支、CALL/RET和WMOV在执行当拍退休，省去等待完成脉冲的空拍。RAM和I/O仍在完成后退休；取指寄存边界保留。
- 三个窄上下文读取选择网络压成两个，按opcode选择源；未增加寄存器文件。
- LOAD、Verify INPUT和WMOV共用256位写数据选择器；共用数据选择，不合并同时存活的节点银行。
- SHAKE固定块保持one-hot选择直接拼接，删除布局编号的重复编码/译码。SHA2前端、Keccak和SHA256轮逻辑不变。

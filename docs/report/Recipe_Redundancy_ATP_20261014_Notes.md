## 最终实现与取舍

采用 `retired_shared_control`（K，`20261014_122421`）。本轮基线直接使用上一轮已接受、完整实测的 `20261014_113650`，不是早期 omega 实验配置。三个关注配置采用同一份 RTL，未增加 P/U 特化。P12U1、P4U1 面积分别下降 1.159%、4.291%；P1U1 面积增加 1.085%，其三个算法 ATP 均小幅回退。三点范围内三个算法的最佳配置仍为 P12U1，最佳 ATP 均下降，因此按既定允许单点回退的规则保留本候选；不能表述为三个配置全面改进。

### 配方与存储冗余

当前 executor 只例化一个 `recipe`，使用完整 `RECIPE_MASK=16'hfffe`；P 个上下文共用一套固定块格式化逻辑。流水展开复制的是 Keccak 轮组合逻辑及必需状态，并未复制 P 个 general recipe。流式与固定请求共用置换状态；不能再按旧多 lane 结构的面积模型估算收益。

本轮将由公共地址域和固定配方形状决定的 `preserve_counter` 从每槽一份改为批次共用一位。仅在所有槽排空后更新，滚动补发继续沿用当前批次规则。公共域、形状切换仍须遵守现有排空握手。

`recipe` 删除独立 `rate_block` 计数和 `rate_block×136` 的末块判断，复用已有字节位置及剩余字节数；保留原有 128 位暂存和每个 136 字节块的最后 8 字节。固定请求已经进入上下文引擎，因此流式长度译码只保留六种流式配方，删除未使用的 `FIXED_ISSUE` 状态。

同时修复精简 mask 的兼容问题：关闭 `PREFIX_LIST` 后，旧代码只填充列表窗口的低 64 位，但生产步长仍为 128 位，会丢失数据。改为统一输出完整 128 位窗口，LMS 的两字节错位选择仍按 mask 裁剪。该修复对生产完整 mask 的逻辑行为不变，不能将其单独计作生产面积收益。旧源码失败、新源码通过的独立日志已归档。

XMSS 的 key、digest、captured 在 KEY/MASK/FINAL 阶段同时存活，三个银行保留。端点、树栈和认证节点已共用工作区；签名缓存与树计算同时存活，不能直接合并。`RECIPE_MASK` 保留为模块能力裁剪接口，没有以算法互斥为由删掉通用核所需的配方。

### 周期与控制冗余

- XMSS 的 67 节点 L-tree 在 67、17、9、5、3 五个奇数层搬移尾节点。搬移后直接推进层号，省去旧 `LT_NEXT→LT_SETUP` 两拍；h10 完整重算 1,024 个叶子，三个 P/U 均实测减少 **10,240 周期**。
- LMS 列表压缩完成后直接进入 `SF_LEAF`，跳过没有功能写入的 `SF_REDUCED`；h10 三个 P/U 均减少 **1,024 周期**。
- 奇数尾搬移与普通批次完成共用层推进控制；删掉已无可达入口的旧标量 L-tree 状态处理、端点结果选择和描述符选择。保留 enum 数值位置，避免改变历史波形观察编号。误入废弃状态仍按非法状态处理。
- SLH-DSA 128f 的周期不变，本轮 ATP 收益来自面积变化。三个算法的 Hash 和置换数均与基线完全一致。

### 实验归因

| 代号／阶段 | 相对修改 | 结论 |
|---|---|---|
| A control_cleanup | 基线加共享计数策略、流式控制清理及精简 mask 修复 | P4 面积下降，P1 回退；周期不变 |
| B ltree_odd_tail | A 加奇数尾节点直达下一层 | XMSS 减少 10,240 周期 |
| C lms_return | B 跳过 LMS 空状态 | LMS 再减少 1,024 周期 |
| D parent_return | C 在哈希返回拍直接写父节点 | 还能减少父节点等待，但综合面积回退，未采用 |
| E original_stream_control | D 恢复原流式计数及译码，保留 mask 修复 | 已完成的 P12/P4 面积均不占优；P1 留后台 |
| F shared_ltree_advance | E 合并 L-tree 层推进分支 | 单独控制合并不能抵消其他改动的面积代价 |
| G narrow_return | F 撤回父节点直接返回 | 保留原寄存返回路径 |
| H compact_control | G 恢复 A 的流式控制清理 | 三个算法最佳 ATP 均改善 |
| I local_counter_policy | H 恢复每槽 preserve_counter | P12 面积回退；P1 耗时 751.2 秒完成，面积也不占优 |
| J retired_ltree_control | I 删除不可达旧 L-tree 控制及选择 | P4 有收益，P12 仍不占优 |
| K retired_shared_control | J 恢复批次共享 preserve_counter | 最终采用；三个配置面积均优于 H |

父节点直接返回方案虽然省周期，却扩大了宽数据寄存器的输入选择；本轮实测不足以抵消面积增加。其他 LUT 变化也受状态机编码、选择器化简和时序驱动映射共同影响，不能把整个候选的 LUT 差额归因于删掉某几位寄存器。每个实验的冻结源码、综合耗时、面积和九项 Sign 日志独立保存，不跨候选拼接结果。

E、I 的 P1 综合耗时偏长，分析没有等待它们；其 P12 结果已经不能满足本轮三目标最佳 ATP 验收。交付时 I 已完成，E 按用户要求继续后台运行。后台结果完成后只补充实验对照，不改变已冻结的最终 RTL。交付归档中的未完成实验是当时快照。

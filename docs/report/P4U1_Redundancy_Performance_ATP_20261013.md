## 冗余与实际损失

原结构的链批次已经有 95.5%～98.1% 的流水级占用率，新增上下文对这些阶段的收益有限。主要损失来自独立串行任务没有进入四上下文调度、每批的收尾与重新发射、宽度只有 64 位的流式生产，以及标量与链两套格式化、key/mask/capture 存储路径。

候选所有批量阶段合计的流水级占用率为 SLH 93.19%、XMSS 96.55%、LMS 98.23%。SLH 此口径新增了只有一个或两个活跃槽的 FORS 父节点阶段，不能与修改前仅链批次的占用率直接比较。XMSS 仍受 L-tree 高层少量独立归约和串行树父节点限制；LMS 列表仍需每叶 16 次置换，SLH 剩余高层父节点继续依赖树栈。

## 实现

1. P4U1 固定块请求统一经过四上下文引擎。标量请求占 tag 0；流式请求继续用共享 sponge。XMSS 二元运算复用 key、digest、captured 银行执行 KEY→MASK0→MASK1→FINAL，captured 临时保存右节点。删除 P4U1 原标量的宽 key/mask/capture 和固定块格式化路径。
2. 公共 tree/layer/family 使用上游已经锁存且在批次中保持稳定的字段；公共域、配方和二元标志按批次共享，槽内只保留 leaf/A/B、步骤、阶段与有效性。无输出捕获的链滚动补发，按每槽链索引写回端点；捕获叶保留按序消费。同拍退槽与补发具有明确优先顺序。
3. XMSS L-tree 每批至多四个二元归约。同批输入全部接受后才开放响应写回，全部完成后推进；奇数尾项沿原路径搬移。同层原地压缩不覆盖下一批尚未读取的输入。
4. P4U1 内部流式生产宽度为 128 位，136 字节率块最后一拍仅使用低 64 位。使用相邻节点的固定窗口处理 16/24/32 字节节点与 LMS 22 字节前缀。端点地址提前登记，使用已有 128 位暂存，不增加完整节点流水寄存器。
5. FORS 四叶组先算两个一级父节点，再算组根。目标秘密节点、低两层认证节点在复用槽前消费或保存；组根从 level=2 接入原树栈，保持签名输出和 ADRS 编码。

其他 P/U 继续沿兼容执行路径。端点 RAM 与 Keccak 轮逻辑的综合层次保留用于抑制选择器跨模块复制，实际取舍由面积实测决定。

## 验证与布线口径

已完成完整十参数三操作、361 项独立 hashlib 字节配方、三族四标签乱序/响应停顿/捕获保留/同拍补发检查，以及 q=0/1/1023、omega2 单槽尾批、消息边界、135/136/137 字节填充、停顿、截断、复位重放、在途异常、统计关闭和其他 P/U 兼容冒烟。Sign 同时逐字节核对生产签名缓存。128f Sign 的 FORS 目标叶低两位覆盖掩码为 f；L-tree 奇数尾项有单独覆盖计数。

原始、修改前、候选使用同器件、同共同核 OOC、同统计关闭与工具设置。先在 6.666667 ns 布线；若失败，按实测关键路径延迟放宽并重跑实现。最终在一份固定物理布线上从 6.666667 ns 按 0.1 ns 递增检查 setup 与 hold，确定该布线的闭合周期。没有增加 false-path 或 multicycle。该数值是本次固定物理实现的 STA 频率，不宣称所有布局种子和板级设计的全局 Fmax。OOC 只约束 clk，未指定 HD.CLK_SRC，报告中时钟网为 unset、BUFGCTRL=0；数据路径完成物理路由，时钟延迟沿用 Vivado 的 OOC 模型。三个对象使用相同口径，结论不扩展到含实际时钟树、ROM、签名缓存及 I/O 延迟的板级 top。

当前基线首轮 150 MHz 布线 WNS = −3.544 ns，hold = +0.094 ns；关键路径 12 级、10.210 ns，布线延迟占 83.889%。当前基线最终固定布线的闭合周期为 10.067 ns，约 99.3 MHz，WNS = +0.002 ns、WHS = +0.085 ns；布线 LUT/FF 为 32,217/11,739，等效面积 9,521.625 Slice。

step10 固定布线闭合扫描记录为 12.566667 ns（约 79.6 MHz），WNS = +0.082 ns、WHS = +0.114 ns；布线 LUT/FF 为 32,149/10,610，等效面积 9,363.5 Slice。按布线面积×执行周期×闭合周期比较修改前基线，SLH/XMSS/LMS 的 ATP 变化分别约为 +16.9%/−1.7%/+19.8%。step10 因而未通过三个目标同时改善的要求；其周期下降不能单独作为 ATP 收益。

step13 在相同周期下综合面积为 9,409.125 Slice，完整十参数三操作回归已通过，布线结果仍待完成。step18 的公共 family 登记试验综合面积为 9,767.375 Slice，已超面积门槛，不作为最终候选。原始基线闭合布线与最终三方 ATP 表尚未完成。

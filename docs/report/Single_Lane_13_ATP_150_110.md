# 单 lane：13 组 128f Sign ATP 排名

固定单 lane，器件 `xc7a200tffg1156-3`，Vivado 2025.2，共同核面积，综合关闭统计。不布局布线。
U1 假定 150 MHz；U2 假定 110 MHz。频率未经布线验证，时间与 ATP 均为估算。

P2U2 按用户指定采用 9.090909 ns、8 线程、-no_timing_driven 的独立诊断综合；其余 12 组为 6.666667 ns、默认时序驱动综合。面积综合口径存在差异，保留并明确标注。

等效 Slice = LUT/4 + FF/8 + 232.4×BRAM36 + 102.4×DSP；LUT 已包含 LUTRAM，不重复计数。
时间(ms) = 计算周期/(MHz×1000)；ATP(Slice·ms) = 等效 Slice×时间。按未四舍五入的 ATP 升序排名。

13 组 Verilator 签名均逐字节匹配软件参考，Hash/置换次数均为 **104937/105641**。BRAM36 和 DSP 均为 0。

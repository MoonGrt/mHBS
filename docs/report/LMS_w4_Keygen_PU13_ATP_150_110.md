# LMS w=4 Keygen：13 个 P/U 配置 ATP 排名

13/13 点综合、13/13 组本参数集 Keygen 仿真通过。输出逐字节比对冻结参考向量；每点 Hash=1,100,799、置换=1,116,159、输出=140 B。

器件 `xc7a200tffg1156-3`，Vivado 2025.2；共同核 OOC 综合约束 6.666667 ns，统计关闭，最多同时运行 6 个 Vivado、每个 4 线程。面积不含外部镜像 ROM 和签名缓存；LUT 已包含 LUTRAM。全部点 BRAM36=0、DSP=0。

**频率仅用于估算**：U1 取 150 MHz，U2 取 110 MHz，沿用此前 SLH 实验的约定值。本轮没有布局布线，也没有验证这些频率在 XMSS/LMS 或各 P 点上可达；因此 ATP 排名是条件性的。时间(ms)=计算周期/(假定 MHz×1000)；等效 Slice=LUT/4+FF/8+232.4×BRAM36+102.4×DSP；ATP=等效 Slice×时间。
